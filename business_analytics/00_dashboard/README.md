# Dashboard

## Overview
This folder contains dashboard outputs built on top of the business analytics layer.

## Purpose
To visualize key business metrics and analytical insights for decision-making.

## Contents
- KPI dashboards
- Customer segmentation visualizations
- Revenue and performance tracking
- Return risk and product performance views

## Data Source
All dashboards are built from validated outputs generated in:

- `business_analytics/00_data_mart/`
- `business_analytics/11_metric_layer/`
- other downstream analytical modules

## Why It Matters
This layer translates analytical results into executive-facing visual outputs,
making trends, risks, and performance drivers easier to interpret.
